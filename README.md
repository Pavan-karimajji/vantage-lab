# vantage-lab

Test bench for Vantage. Generates dummy components (A, B, C, …) from short
topology files, runs them in a fake car to produce recordings with a known right
answer, and keeps the catalogue of corner cases Vantage must reproduce exactly.

Designed in `vantage/docs/VANTAGE_Lab_Design.md`; developed inside the
`vantage-dev` workspace (`VANTAGE_DEV_PLAN.md`).
